# Portfolio Website 

A modern, high-fidelity developer portfolio built with React, Vite, and Tailwind CSS. Features a dark-themed UI, subtle glassmorphism effects, interactive terminal elements, and responsive designs.

##  Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **Icons:** FontAwesome
* **Components & Libraries:** Swiper.js
* **Deployment:** GitHub Actions / GitHub Pages

##  Key Features

* **Dark Theme UI:** Custom color palette with glowing pink accents.
* **Responsive Design:** Optimized layout for Desktop, Tablet, and Mobile screens.
* **Interactive Terminal Snippet:** Showcase key developer details in code format.
* **Modular Components:** Structured data model for Experience, Education, and Skills.
